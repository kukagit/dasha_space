# Dasha Space

Сайт-квест-открытка на день рождения, вдохновлённый «белым пространством» из Omori.
Чистый HTML + CSS + JavaScript, без сборки и без бэкенда — деплоится на GitHub Pages в один клик.

## Геймплей

1. Заставка → нажми «Начать».
2. Ты в белом пространстве. Управление: **WASD** / **стрелки**.
3. По углам стоят 4 NPC. Подойди к каждому и нажми **E** (или **Space** / **Enter**) — поговори.
4. Каждый NPC отдаёт кусок кода. Прогресс сохраняется автоматически (localStorage).
5. В центре карты — постамент. Подойди к нему, нажми **E**, введи собранный код.
6. Если код верный — финальная открытка с конфетти и музыкой.

По умолчанию пароль: **DASHA182026** (склейка `DA` + `SHA` + `18` + `2026`). Поменять — в `src/config.js`.

## Запуск локально

В корне репо запусти любой статический сервер:

```bash
python3 -m http.server 8000
# открой http://localhost:8000
```

Открыть `index.html` напрямую файлом не получится — используются ES-модули, для них нужен http(s).

## Кастомизация

Вся настройка — в одном файле: [`src/config.js`](src/config.js).

| Что меняется | Где |
|---|---|
| Имя именинника, тексты заставки и открытки | `intro`, `ending` |
| Реплики 4 NPC, имена, позиции | `npcs[]` |
| Кусочки пароля и итоговый пароль | `npcs[].passwordPart`, `password` |
| Скорость игрока, точка спавна | `player` |
| Размеры мира, цвет/картинка фона | `world` |
| Музыка и громкость | `audio`, `ending.music` |

### Подмена картинок

Все спрайты — **32×32 PNG** (как в Omori). Игрок и NPC рендерятся пиксель-перфект (`image-rendering: pixelated`), так что не масштабируй их перед сохранением.

Положи свои файлы в `assets/images/` под этими именами:

- `player.png` — игрок (32×32)
- `npc1.png` … `npc4.png` — четыре NPC (32×32)
- `altar.png` — центральный объект (32×32, опционально, иначе нарисуется ромб с «?»)
- `background.png` — фон локации (рекомендуется 800×600)
- `card.png` — картинка финальной открытки (любой размер, но не очень большая)

Чтобы сгенерировать стоковые плейсхолдеры заново:

```bash
python3 scripts/gen_placeholders.py
```

### Подмена музыки

Положи в `assets/audio/`:
- `bgm.mp3` — фоновая музыка (loop) во время игры
- `ending.mp3` — музыка для финальной открытки

Если файла нет — звук просто не будет играть (без ошибок).

## Деплой на GitHub Pages

1. Запушь репозиторий на GitHub (публичный).
2. На GitHub: **Settings → Pages**.
3. **Source**: `Deploy from a branch`.
4. **Branch**: `main`, папка `/ (root)`. Сохрани.
5. Через ~30 секунд сайт будет доступен по адресу:

   `https://<твой-username>.github.io/dasha_space/`
